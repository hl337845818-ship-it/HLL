# AI 学习提示词小花园

这是一个用于讲解 Git、GitHub 和 VS Code 的练习项目。
不需要安装 Python，不调用 AI 接口，也不需要 API Key。

## 文件

- prompts.txt：今天要修改和提交的提示词。
- resources.md：4 个 AI 学习仓库。
- .gitignore：排除本地环境、密钥文件和临时文件。

## 演示目标

1. 打开 prompts.txt，查看修改前后的区别。
2. 在 VS Code 源代码管理中暂存这个文件。
3. 提交说明填写 improve study prompt。
4. 有 GitHub 登录和网络时，发布为自己的 Private 仓库。

Git 的提交留在本地。推送成功后，GitHub 才会出现新的提交。

## 准备状态

项目已初始化为独立 Git 仓库，目前尚无提交，四个文件均待首次暂存。
首次提交前，请在 VS Code 终端中配置自己的提交署名与邮箱。
演示前可在此仓库配置自己的署名与邮箱，不必改动全局配置。
